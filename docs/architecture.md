# Architecture

The application uses feature-first modules. `app` composes providers, routes and layouts. A feature owns its pages, components, schemas, hooks and services. `shared` contains domain-neutral UI and infrastructure and must never import features or app. Cross-feature use goes through a deliberate public contract, not another feature's internals.

Data flow: React page → feature hook → service → centralized Axios → NestJS API. TanStack Query owns remote cache and asynchronous state. React owns local component state; React Hook Form owns form state. Zustand is installed for a future concrete global UI need and is not used as a remote cache. There is no store until that need appears.

After login the app opens `/management`; every protected route requires a valid session restored from the versioned `localStorage` payload (or created by login) and a backend-confirmed management context. The persisted session carries `expiresAt` derived from the backend `expiresIn`; expired, corrupt or unsupported payloads are discarded and require a new login. `POST /api/v1/desktop/auth/login` supplies the token, desktop roles and optional `teacherId`/`caveId`; role-specific routes are `/platform/caves`, `/platform/users`, `/teachers`, `/schedules`, `/memberships` and `/workouts`. The context selection screen lists `GET /api/v1/management/contexts` and confirms the choice with `POST /api/v1/management/contexts/switch`; the confirmed context is persisted so a reload keeps the same workspace, there is no local fallback context, and switching clears scoped query caches without replacing the JWT. The legacy `/academies`, `/classes` and `/evaluations` routes remain for existing features. `/preview/academies` and `/preview/management/*` are development-only visual QA routes, registered only when `import.meta.env.DEV` is true and never linked from the product. The backend remains the authority for domain rules and authorization.

The neutral color tokens support light/dark mode. They are provisional pending Caverna Figma tokens.
