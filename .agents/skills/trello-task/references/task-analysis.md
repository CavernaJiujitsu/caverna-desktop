# Card intake

Search by exact URL/ID first. For name or list searches, compare candidates and ask on ambiguity. Record card URL, title, status, list, labels, owner, description, checklists, relevant comments and attachments when accessible. Quote or paraphrase the source accurately and label each inference. Check linked designs and API references before claiming a contract exists.

Classify ownership: frontend UI/integration, NestJS backend, infrastructure or mixed. Split mixed work into dependencies; do not create backend code in this repository. A card lacking enough detail can still receive an analysis with explicit open questions.
