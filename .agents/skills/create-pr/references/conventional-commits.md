# Branches and commits

Use `feat/<task-id>-<short-name>`, `fix/<task-id>-<short-name>` or `refactor/<short-name>`. Omit the ID when none is present; never invent one. Keep names lowercase and descriptive.

Commit form: `<type>(<scope>): <imperative summary>`, for example `feat(academies): add academy list`. Common types: `feat`, `fix`, `refactor`, `test`, `docs`, `chore`. Include only reviewed files. Bootstrap may follow its explicit one-time publication instruction; normal feature work targets a PR.
